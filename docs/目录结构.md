## 本地运行时产物（gitignore，不入库）

| 路径 | 说明 |
| --- | --- |
| `backend/manifest/config/config.yaml` | 本机真配置 |
| `backend/manifest/sql/seed-credentials.sql` | 本机口令种子 |
| `backend/data/*.db` | SQLite 库 |
| `frontend/node_modules/`、`frontend/dist/` | 依赖与构建产物 |

## 开发端口

| 端口 | 用途 |
| --- | --- |
| 5176 | 前端 Vite |
| 8082 | 后端默认监听 |
| 18082 | 可选；与边端同机对拍时后端改听此口，前端默认代理目标 |
