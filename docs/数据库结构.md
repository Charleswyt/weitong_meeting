# 卫通会议（云端）· 数据库结构

- **引擎**：SQLite，单文件 `backend/data/conference.db`  
- **建表真源**：`backend/manifest/sql/sqlite_create.sql`  
- **口令**：不在建表脚本；可选本机 `seed-credentials.sql`（gitignore）  
- **约定**：表名小写、列名大写；时间列无 DB 默认值（由 Go 写入）；WAL + `busy_timeout`

`go run .` 首次会按脚本幂等建表（`CREATE TABLE IF NOT EXISTS` + `INSERT OR IGNORE`）。

## 表一览

| 表 | 用途 |
| --- | --- |
| `sys_dict_type` | 字典类别 |
| `sys_dict_data` | 字典取值 |
| `sys_dept` | 部门 |
| `sys_user` | 用户 |
| `user_settings` | 用户偏好 |
| `meeting_appointment` | 会议预约 |
| `meeting_participant` | 预约参会人 |
| `meeting_attendance` | 入会考勤（`(meeting_id,user_id)` 唯一） |
| `meeting_deleted` | 会议删除标记 |
| `recording_deleted` | 录制删除标记 |

## 关系（逻辑，无物理外键）

```
sys_dept 1—* sys_user
sys_user 1—1 user_settings
meeting_appointment 1—* meeting_participant
meeting_appointment 1—* meeting_attendance
sys_user           1—* meeting_participant / meeting_attendance
sys_dict_*           被业务列以 DICT_VALUE 引用
```

## 改表

改 `sqlite_create.sql`（或增加 `alter_*.sql`）后对本机库执行 migrate；不要对 SQLite 执行达梦历史 `create.sql`。备份即拷贝 `data/conference.db`。
