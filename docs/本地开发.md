# 卫通会议（云端）· 本地开发

拿到本树源码后即可改、可跑。不依赖 Docker / 预构建包。

## 依赖

| 项 | 版本参考 |
| --- | --- |
| Go | 见 `backend/go.mod`（`go 1.26`） |
| Node / pnpm | 见 `frontend/.nvmrc`、`frontend/package.json` 的 `packageManager` |
| 出网 | 调三方会议控制面时需要能访问配置里的 `thirdParty.conference.baseUrl` |

## 后端

```text
cd cloud/backend
copy manifest\config\config.yaml.example manifest\config\config.yaml
# 编辑 config.yaml：填 jwt / 三方 / 邮箱等 __REPLACE_ME__
# 默认 deployment.side: cloud；监听 :8082（可改）
go mod download
go run .
```

- 库文件：`backend/data/conference.db`（首次启动按 `manifest/sql/sqlite_create.sql` 建表）  
- 口令种子：本机可放 `manifest/sql/seed-credentials.sql`（gitignore，不入库）  
- 改 API 形状：先改 `../contracts/`，再改 handler / 前端类型

## 前端

```text
cd cloud/frontend
pnpm install
pnpm dev
```

- 开发口 **5176**，默认把 `/api` `/ws` `/assets` 代理到 `http://localhost:18082`  
  （若后端听 8082，设环境变量 `VITE_BACKEND=http://localhost:8082` 或改 `vite.config.ts`）  
- 改了 `../contracts/api.openapi.yaml` 后执行：`pnpm run gen:types`
