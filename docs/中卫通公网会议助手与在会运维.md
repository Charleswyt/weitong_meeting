# 中卫通公网会议助手与在会运维

适用于中卫通公网会议、原 ROI 公网监控台和阿里云会议服务。更新于 2026 年 11 月 25 日。

## 更新前查看在会人员

用 ROI 超级管理员账号登录监控台，在首页导航查看「中卫通公网会议」。卡片每 5 秒刷新，也可点击立即刷新。正在使用时显示会议号、在会人数、参会显示名和媒体发布数。关闭全部摄像头、麦克风的参会人仍占一个在会名额。正常离会会及时移除，异常断线可在最后一次有效会议心跳后保留至多约 120 秒。出现「状态未知」时暂缓更新。[公网 ROI 监控台](https://47.114.83.151/)

会重启会议控制或媒体服务的发布，应在阿里云主机使用 `/usr/local/sbin/weitong-meeting-release-guard acquire`。此操作原子核对成员和发布轨道，有人在会时返回 HTTP 409 并以非零退出。成功后会暂时拒绝新入会，发布完成执行 `/usr/local/sbin/weitong-meeting-release-guard release`。维护窗口 90 秒自动失效，包含耗时构建、下载的发布应先完成这些步骤，再申请窗口。监控台展示和发布检查使用同一实时来源。

## 会前、会中与会后

| 时机 | 入口 | 操作 |
| --- | --- | --- |
| 会前 | 预约会议 → 会议详情 → 材料与会议助手 | 主持人发布文件。受邀人可逐件下载或一次领取 ZIP。每件最多 16 MiB，每场最多 64 件、合计 64 MiB。领取人数按账号去重。 |
| 会中 | 会议工具栏 → 会议助手，窄屏在「更多」中 | 参会人可开启自己的发言转录、选择字幕语言、绑定或撤销本人声纹。主持人可以导入术语库、开始加密录制、生成和修订纪要。 |
| 会后 | 会议详情 → 材料与会议助手 | 实际参会人可查看转录、翻译和已发布纪要。录制副本按该次录制选定的回放范围提供。 |

麦克风转录由本人开启。浏览器复用已授权的会议音轨，以短句向阿里云发送 16 kHz 单声道语音。关闭会议助手面板可继续转录，点击「停止转录我的发言」、静音或离会会停止该端采集。服务保留识别原文、术语修正文本、发言时间和署名。声音通常按参会麦克风区分，同一麦克风也可以匹配本场已绑定的声纹。匹配置信度不足时保留麦克风署名。声纹绑定需要本人同意并连续讲话约 4 秒，服务只保留按会议和账号加密的向量。多人同麦同时抢话时，单段可能只能得到一个署名。

语音识别使用 SenseVoice，支持普通话、粤语、英语、日语和韩语。字幕可译为中文、英语、日语、韩语、法语、德语、西班牙语或俄语。每位观看者独立选语言，相同片段的同语种译文会复用。识别和翻译在阿里云本机运行。[SenseVoice](https://github.com/FunAudioLLM/SenseVoice) · [M2M100](https://huggingface.co/facebook/m2m100_418M)

## 行业术语与纪要

预置标准词包括 Ka 卫星、边云协同、LoRA、昇腾、DCU、水电站和船舶 CCPD。主持人可在「术语库」导入 UTF-8 CSV 或 JSON。第一列为标准词，后续列可写多个别名。新词库对后续发言生效，已记录的原文与修正结果均可追溯。

```csv
标准词,别名
Ka 卫星,卡卫星,Ka卫星
昇腾,升腾,生腾
船舶 CCPD,船舶CCPD,船舶 C C P D
```

「会议纪要」从已有转录整理讨论摘要、决定、行动项和待确认问题，每条带发言人、北京时间和来源编号。主持人可校订和保存，实际参会人可导出 Markdown。多人同时编辑时，以修订号检查覆盖冲突。

### 后续接入阿里云智能纪要（待开发）

现网纪要按关键词把发言原文归入各栏目。下一版拟接入阿里云百炼的通义听悟智能纪要。会中继续由自建会议服务做转录、发言人匹配、术语校正和实时翻译。会后由主持人点击生成，将本场已转录并经术语校正的原语言发言按顺序提交给听悟。每行包含本场发言人代号和发言内容，有转录即可生成，会议录制可按原有需求独立选择。[听悟离线纪要接口](https://help.aliyun.com/zh/model-studio/tingwu-meeting-offline-api-create-task)

服务端使用已发布的听悟应用 ID 和百炼 API Key 创建纯文本任务，保存返回的 `dataId` 并异步查询结果。同一份转录重复点击时复用任务。每次提交在本平台保留发言代号、句子编号与原转录的对应关系。拟生成的决定和行动项应能回查原文，负责人或期限缺少依据时标为待确认。结果先供主持人校订，再按现有修订号保存；任务返回前如已有人工改稿，由主持人选择是否采用新草稿。[听悟任务结果接口](https://help.aliyun.com/zh/model-studio/tingwu-meeting-offline-api-get-task)

纪要按纯文本输入量估算费用。上线前用一份带行业术语和明确待办的测试稿，核对署名、原文引用、人工修订和用量。实时字幕容量另行压测，在 10 人入会时改变同时讲话人数和目标语种数，记录从一句话说完到译文显示的第 95 百分位延迟。现有双人验收覆盖功能，十人并发翻译容量仍待测量。[听悟纯文本计费说明](https://help.aliyun.com/zh/model-studio/tingwu-meeting-summary-overview)

## 录制、加密和水印

1. 主持人打开「加密云录制」，选择回放范围，可选仅主持人、实际参会人或指定账号 ID。
2. 每位参与者分别授权摄像头、麦克风和共享屏幕。授权仅对本次入会生效，可以中途撤销。云端从现有会议媒体通道录制已发布且获准的轨道。
3. 主持人结束录制后，可导出收到有效媒体帧的轨道。录制落盘使用分块 AES-256-GCM，随后将密文异步存入私有 OSS，核对大小和 CRC64 后页面显示「已归档至 OSS」。
4. 导出时，服务按领取人再次鉴权，把会议号、领取账号 ID、录制 ID 和领取流水嵌入画面，水印位置随播放时间变化。麦克风单轨导出为带声音和水印画面的 MP4。
5. 「导出水印 MP4」可在普通播放器打开。「下载加密水印副本」会在浏览器使用口令加密为 `.wtrec`。接收人可在会议助手的「本地加密文件」中输入口令播放。该处也可给已有本地录制制作加密副本。口令由双方自行传递，平台无法恢复遗失的口令。

原有「本地录制」继续按用户所选位置保存。需要受控分发时请选择加密水印副本。已经发给接收人的离线文件使用交付时的口令，后续调整会内权限只影响新的领取请求。

## 接口与验收

公网 ApiPost 集合第 07 组收录在会状态、增量转录、声纹、术语、翻译、材料、录制授权、录制导出、纪要与修订。会议助手使用中卫通登录返回的 Bearer，运维状态使用 ROI 超级管理员 Bearer。转录分片以 `Idempotency-Key` 去重。接口示例使用虚构账号和会议号。[ApiPost 集合](https://47.114.83.151/zwt-meeting/apipost.json) · [OpenAPI](https://47.114.83.151/zwt-meeting/api.openapi.yaml)

2026 年 11 月 25 日在公网用两个临时会议账号验收。两人都在会且媒体发布数为零时，ROI 显示两人，发布检查返回 409。受邀人会前下载了 ZIP。浏览器麦克风产生了转录，英文和中文片段分别译到另一语种，声纹绑定、匹配及撤销均通过。主持人生成并保存了第二版纪要，参会人可下载，修改纪要返回 403。

公网 Chromium 客户端使用模拟摄像头和麦克风实际发送 WebRTC 媒体，两条云录制轨道均成功导出并解码。另用可重复的 H.264 和 Opus 源验证，两个账号领取同一摄像头录制得到的首帧像素不同，音频副本同时含声音和水印视频轨。私有 OSS 中两份对象的密文文件头、大小和 CRC64 已核对。离线加密使用跨块样本验证了还原、错口令、截断和篡改。上述验收覆盖测试账号与模拟信号，现场多人同麦的识别准确率尚未做定量测评。
